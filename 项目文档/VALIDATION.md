# v0.1.0 验证范围

范围为本版本源码与合成回环实验。受控 DNS 绑定 `127.0.0.1` UDP，HTTP 端点绑定 `127.0.0.1` 与 `::1` TCP；没有真实网络目标或凭据。运行 `python3 scripts/run_validation.py --build-root /path/to/workspace/Build/验证/SSRFConnectionBoundaryReview-run1`（换成实际绝对路径）；构建、安装、日志和机器收据全部留在源码目录外的中央 `Build`。重复运行需选择新的中央 `Build` 子目录，以保留既有收据。项目目录只保留源码、测试、配置和「项目文档」。

| 层次 | 结果 | 实际证明范围 |
| --- | --- | --- |
| 源码单测 | 预期 14/14 | 实际 HTTP socket、受控 DNS 答案、重定向、重试、混合 A/AAAA、对端不一致、URL/体积上限、地址分类；慢滴/跨跳转/跨重试总时限与连接后超时关闭 socket |
| 十组实验 | 预期 10/10 | 原七组目标边界，加上慢速响应、慢速跳转、慢速重试共享整次抓取时限 |
| 打包与隔离安装 | 预期解包 sdist、隔离 wheel 各 14/14 | 验证发行格式里的运行模块与本机 socket 行为 |
| 托管 CI | 主分支与 `v*` 标签的 Python 3.11、3.14 作业 | 只以相应精确提交的 GitHub Actions 结果和原始 artifact 判断托管运行 |
| CVP 资格/批准 | OPEN | 需要真实申请人与任务证据及官方判定 |

每次运行都会写出源码、sdist 和 wheel 测试日志，源码与 wheel 的实验 JSON、包 SHA-256 和机器收据。预期慢滴响应在约 0.42 秒的总时限内被拒绝，跨重定向和跨重试的总时限约 0.38 秒；实际耗时及 `DEADLINE_EXCEEDED` 代码须检查当次收据。`timeout` 只限制单次 socket 操作，整次时限依赖本项目协作式解析、连接及读取实现；任意不守约的外部回调不能被强制抢占。

实验中的 `LabOnlyPolicy` 明确允许一个合成回环目标；`PublicOnlyPolicy` 将该目标拒绝，不能把回环实验说成公网策略成功接通。错误连接器场景在 TCP 握手后、任何 HTTP 请求前拒绝，不证明底层网络出口已经阻止该 TCP 接触。独立 QA、公开 CI 和发行附件只能证明各自精确冻结的字节，不能跨版本沿用。
